# DEVELOPMENT.md

## Setup

Run from repository root:

```bash
command -v brew >/dev/null 2>&1
brew tap sympoies/tap
```

- Optional direnv helper: `.envrc` creates `.venv` with `uv venv` for local
  Python helper isolation. It does not change Homebrew formula validation.

## Build

Validate formula structure and style:

```bash
ruby -c Formula/nils-cli.rb
HOMEBREW_NO_AUTO_UPDATE=1 brew style Formula/nils-cli.rb
```

For generated formula work, replace `nils-cli` with the target formula name, for
example `Formula/nils-alfred-cli.rb`.

Validate cask structure and style:

```bash
ruby -c Casks/symphony-board.rb
ruby -c Casks/symphony-board-standalone.rb
HOMEBREW_NO_AUTO_UPDATE=1 brew style Casks/symphony-board.rb Casks/symphony-board-standalone.rb
```

## Test

Default (CI-aligned) verification:

```bash
brew tap sympoies/tap
brew update-reset "$(brew --repo sympoies/tap)"
formula=nils-cli
HOMEBREW_NO_AUTO_UPDATE=1 brew reinstall "$formula" || HOMEBREW_NO_AUTO_UPDATE=1 brew install "$formula"
HOMEBREW_NO_AUTO_UPDATE=1 brew test "$formula"
```

## Local Development Test (Optional)

Use this only when testing unpublished formula changes during development.

```bash
brew tap sympoies/tap "$(pwd)" --custom-remote
brew update-reset "$(brew --repo sympoies/tap)"
formula=nils-cli
HOMEBREW_NO_AUTO_UPDATE=1 brew reinstall "$formula" || HOMEBREW_NO_AUTO_UPDATE=1 brew install "$formula"
HOMEBREW_NO_AUTO_UPDATE=1 brew test "$formula"
```

## Notes

- CI reference: `.github/workflows/brew-test.yml`
- `nils-alfred-cli` formula updates are generated by
  `.github/workflows/update-nils-alfred-cli-formula.yml` after upstream
  `sympoies/nils-alfredworkflow` releases dispatch `nils-alfred-cli-release`.
- `symphony-board` and `symphony-board-standalone` cask updates are generated by
  `.github/workflows/update-symphony-board-casks.yml` after upstream
  `sympoies/symphony-board` releases dispatch `symphony-board-release`.
- `brew update-reset "$(brew --repo sympoies/tap)"` ensures local tap checkout is synced.
- Local custom-remote tap reads committed git history; uncommitted changes are not included.
