# Development log - 2026-05

## 2026-05-29 - Release-dispatched formula updates became authoritative

### Result

- The tap gained an upstream release-dispatch workflow that renders and
  validates nils-cli formula updates, then writes attributable signed commits
  through the provider API.

### Why / context

- High-frequency formula bumps needed to be derived from immutable upstream
  release assets without relying on a mutable maintainer checkout or unsigned
  automation commits.

### Evidence

- Commits `51b90aa` and `9315773` capture the generator, local-tap
  installation validation, and Contents API signing after closing checkout-path
  failures discovered during rollout.
