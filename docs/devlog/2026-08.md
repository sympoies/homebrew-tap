# Development log - 2026-08

## 2026-08-03 - Manual formula recovery became race-safe

### Result

- The nils-cli recovery workflow now requires the exact inspected tap commit
  and refuses to generate or write if the default branch moved.

### Why / context

- A manual recovery dispatch can otherwise validate one repository state and
  write onto another after a concurrent generated bump.

### Evidence

- PR #13 added the expected-commit guard, workflow regression coverage, and the
  matching maintenance note in `DEVELOPMENT.md`.
